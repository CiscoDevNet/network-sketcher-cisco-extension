# Required third-party dependency (confirmed decision, see DESIGN.md

networkx>=3.0
# Used for BOTH:
#   (a) requirement D's tier/area layout, ported from
#       3rd_party/netbox_converter/src/netbox_layout.py (connected_components /
#       degree_centrality / neighbors), and
#   (b) requirement C's k>=3 (and flagged k==2) shared-subnet resolution,
#       where the Blossom algorithm (networkx.algorithms.matching.min_weight_matching)
#       is the default and preferred matching_algorithm (see
#       config_converter_to_ns_config.json). A stdlib-only brute-force fallback
#       remains available (matching_algorithm="brute_force") for environments
#       where networkx cannot be installed, but it is no longer the default.
# Version pin matches the existing precedent in
# 3rd_party/netbox_converter/requirements.txt.

# No config-parsing library is used: config_parser.py is stdlib-only (see
# DESIGN.md section 4.2.2). A GPL-licensed parser would be incompatible with
# this repository's Apache-2.0 licence, and measurement showed such a library
# added no extraction accuracy over the indentation-agnostic section scanners.
#
# Do not add any other third-party dependency without documenting why here,
# per template_converter/GUIDE.md's "stdlib unless truly necessary" rule.
